Personal wine label package

Wine slug: shmelev_shmeleva_risling
EAN-13: 4618081983745

PRINT
Open shmelev_shmeleva_risling_A4_print.pdf.
Use A4 portrait paper. Use color mode and 100% scale.
Do not use the fit-to-page option.
The sheet has two label pairs.
Cut on the gray dashed rectangles. The gold border stays on each label.
The sheet has 2 mm of artwork bleed outside each cut line.
Check that the reference line at the bottom measures 50 mm.

SIZES
Front: 90 x 120 mm.
Back: 80 x 120 mm.
The separate PDFs use the final cut size. They have no cut marks.
The separate PNG files use 600 dpi. They have no cut marks.

DATASET
metadata.json stores the wine slug, label copy, barcode, image sizes,
and image checksums. The barcode has a valid EAN-13 check digit.
OpenCV decoded the barcode from the rendered back label.
This package does not import data into the active dataset.
The label and barcode are personal creative test material.

SOURCE
build_labels.py uses ReportLab and the system Georgia and Arial fonts.
All label artwork is vector artwork in the PDF files.
The PDF files embed the fonts used by the label text.
preview.png is a screen preview. Use the A4 PDF for printing.
