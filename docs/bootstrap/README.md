# Развертывание моделей для хакатона

Эти инструкции помогают организатору хакатона запустить локальные эндпоинты инференса.

## Когда нужен bootstrap

Рабочий комплект ML-сервисов проекта уже развернут и работает на GX10 (NVIDIA DGX Spark).
Организатор MAY использовать готовые HTTP-эндпоинты на GX10.
Для этого клиентские компоненты MUST иметь доступ к частной сети GX10.
Организатор MAY использовать bootstrap, если он хочет запустить ML-сервисы на своем хосте.

Остальные компоненты системы используют HTTP-эндпоинты.
Они не загружают ML-модели в свои процессы.
Исключением является Android-приложение.
Адреса сервисов задают переменные среды.
Поэтому ML-сервисы MAY работать на другом хосте или в другой среде инференса.

## Сетевая модель

Bootstrap предназначен для доверенной частной сети.
Сервисы bootstrap не выполняют аутентификацию.
Прямой доступ к этим сервисам MUST быть разрешен только из доверенной частной сети или через SSH-туннель.
Не публикуйте порты bootstrap в Интернете или в недоверенной сети.
Для такой публикации используйте внешний шлюз с TLS, аутентификацией и ограничением частоты запросов.
Этот внешний шлюз не входит в bootstrap.

## Выбор среды инференса

`siglip2-so400m-patch16-naflex` и `siglip2-so400m-patch16-512` являются альтернативами.
Выберите только одну из этих моделей.
Не запускайте обе модели одновременно.

Ollama является опорной средой инференса для `qwen3.5:9b`.
Организатор MAY использовать другую среду инференса.
Эта среда MUST предоставлять совместимый эндпоинт `POST /v1/chat/completions`.
Задайте адрес и имя модели через `VLM_ENDPOINT` и `VLM_MODEL`.

## Получение исходного кода

Исходный код находится в приватном репозитории [s1mb1o/svoe-vino-lab-dev](https://github.com/s1mb1o/svoe-vino-lab-dev).
Эта инструкция использует ветку `main`.
Владелец репозитория MUST дать организатору доступ на чтение.
Организатор MUST добавить свой SSH-ключ в GitHub.

Выполните команды:

```sh
git clone --branch main --single-branch \
  git@github.com:s1mb1o/svoe-vino-lab-dev.git \
  svoe-vino-lab
cd svoe-vino-lab
```

## Общие требования

- Не менее 80 GiB свободного места на диске
- Исходящий HTTPS-доступ к GitHub, Google Drive, PyPI и индексу пакетов PyTorch

Архивы моделей используют приблизительно 20 GiB.
Во время установки на диске одновременно находятся архивы, извлеченные модели, пакеты Python и временные файлы.
Требования к памяти и GPU зависят от платформы и описаны в [`../../bootstrap/README.md`](../../bootstrap/README.md).

Выберите платформу:

- [Apple Silicon](apple-silicon.md)
- [Selectel с NVIDIA GPU](selectel-rtx4090.md)

Исходный код эндпоинтов находится в [`../../bootstrap/`](../../bootstrap/).

## Где скачать модели

Архивы моделей и `manifest.json` находятся в [папке Google Drive](https://drive.google.com/drive/folders/1k_suN_6i6jaaS_ti1Lsm5xUypy5vh4HQ).

Дождитесь завершения загрузки всех файлов.
Перед скачиванием убедитесь, что в папке видны следующие пять файлов:

- `manifest.json`
- `facebook--sam3.tar`
- `google--shieldgemma-2-4b-it.tar`
- `google--siglip2-so400m-patch16-naflex.tar`
- `google--siglip2-so400m-patch16-512.tar`

Не изменяйте имена файлов.
Скачайте каждый файл полностью.
Установщик проверит размер и SHA-256 каждого архива по данным из `manifest.json`.

Репозиторий не содержит лицензированные архивы моделей.
Передавайте архив с ограниченным доступом только получателю, который принял применимое лицензионное соглашение модели.

Qwen3.5-9B не входит в эту папку.
Инструкции используют Ollama для скачивания и запуска `qwen3.5:9b`.
Модель ShieldGemma нужна только для модерации изображений в `telegram-bot`.
