SEO-006: Unknown producer map /lineup/<id> returns 200 instead of 404
<!-- labels: bug -->

**Priority:** P2 · **Effort:** S · **Status:** VERIFIED

## Evidence

`https://chtozavino.ru/lineup/nonexistent` → 200, title «Карта производителя не найдена — Что за вино?», `noindex`. This is a soft 404.

## Where

[`webui/app/pages/lineup/[producer].vue:13–18`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/app/pages/lineup/[producer].vue#L13-L18): a missing map becomes `null` and renders a fallback.

## Fix

```ts
if (!line.value) throw createError({ statusCode: 404, statusMessage: 'Карта производителя не найдена' })
```

Tell an unknown ID apart from a temporary loader error. Show the message on the error page (SEO-023).

## Verify

`curl -s -o /dev/null -w '%{http_code}' https://chtozavino.ru/lineup/nonexistent` → 404; known maps → 200.
