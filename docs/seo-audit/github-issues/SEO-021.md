SEO-021: Preload the LCP background image /reference/background.webp
<!-- labels: enhancement -->

**Priority:** P2 · **Effort:** S · **Status:** VERIFIED

## Problem

On every checked page the LCP element is `div.site-shell`. Its paint is the CSS background `.site-shell:before { background: url('/reference/background.webp') … }` (93 KB). The browser finds it only after the CSS loads.

## Evidence (Lighthouse mobile, `/`, run 2)

- «Preload LCP image» fails.
- LCP phases: TTFB 615 ms, load delay 1,638 ms, load time 71 ms, render delay 1,441 ms.

## Where

[`webui/app/assets/main.css:108`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/app/assets/main.css#L108); head links in [`webui/nuxt.config.ts:62–66`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/nuxt.config.ts#L62-L66).

## Fix

Add to `app.head.link`:

```ts
{ rel: 'preload', as: 'image', href: '/reference/background.webp', type: 'image/webp', fetchpriority: 'high' },
```

## Verify

Lighthouse «Preload LCP image» passes; LCP load delay on `/` < 500 ms (lab, same machine).
