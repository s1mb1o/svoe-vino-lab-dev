SEO-020: Confirm chtozavino.ru in Yandex Webmaster and Google Search Console; submit the sitemap

**Priority:** P1 · **Effort:** S · **Status:** REQUIRES VERIFICATION

## Problem

The audit found no sign that the site is verified in Yandex Webmaster or Google Search Console. Without them, nobody can see indexed pages, queries, snippets or crawl errors in the Russian market.

## Evidence

- No `yandex-verification` or `google-site-verification` meta tag in the HTML.
- DNS TXT for `chtozavino.ru` has only the SPF record.
- An HTML-file verification leaves no trace in HTML or DNS, so the state is unknown.
- Anonymous requests to all sitemap URLs return 200, so the site-wide HTTP Basic (#77) no longer blocks crawlers.

## Steps (owner)

- [ ] Yandex Webmaster: add or confirm `https://chtozavino.ru`; set «Региональность» to Россия; add `https://chtozavino.ru/sitemap.xml`; request «Переобход» for `/`, `/shelf`, `/dish`, `/shelf-lens` (after release).
- [ ] Google Search Console: add or confirm the domain property; submit the sitemap; URL Inspection → live test of `/` (check the rendered HTML keeps the page content under the age gate).
- [ ] After 1–2 weeks: read Yandex «Диагностика сайта», «Страницы в поиске»; Search Console «Pages». Record the baseline in `webui/ResearchLog.md`.

## Verify

Both tools show the site verified and the sitemap processed without errors.
