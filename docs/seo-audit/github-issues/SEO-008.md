SEO-008: /dish sends the home page link preview (og:url, og:title, og:description)
<!-- labels: bug -->

**Priority:** P2 · **Effort:** S · **Status:** VERIFIED

## Problem

`/dish` has its own `<title>`, description and canonical, but its Open Graph and Twitter tags are the home page values. A link to `/dish` in Telegram, VK or MAX shows the home-page card. `og:url = https://chtozavino.ru/` is also a weak duplicate signal to `/`.

## Evidence

```
$ curl -s https://chtozavino.ru/dish | grep -o '<meta property="og:[a-z]*" content="[^"]*"'
og:url         https://chtozavino.ru/
og:title       Найти вино по фото — Что за вино?
og:description Сфотографируйте этикетку российского вина. …
```

## Where

- [`webui/app/pages/dish.vue:2–5`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/app/pages/dish.vue#L2-L5) sets only `title`, `description` and `canonical` with `useHead`.
- The global defaults in [`webui/nuxt.config.ts:45–53`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/nuxt.config.ts#L45-L53) stay.

## Fix

Use `useSeoMeta`, as `shelf.vue` does. Keep the literal canonical string, because `webui/tests/seo.test.ts` checks it.

```vue
<script setup lang="ts">
const title = 'Вино к блюду — Что за вино?'
const description = 'Подберите российское вино к блюду: по фотографии или названию, с учётом соуса и ваших пожеланий.'
useSeoMeta({ title, description, ogType: 'website', ogTitle: title, ogDescription: description, ogUrl: 'https://chtozavino.ru/dish', twitterTitle: title, twitterDescription: description })
useHead({ link: [{ rel: 'canonical', href: 'https://chtozavino.ru/dish' }] })
</script>
```

## Verify

- `curl -s https://chtozavino.ru/dish | grep og:url` shows `/dish`.
- Telegram `@WebpageBot` shows the dish card.
