SEO-015: JSON-LD: keep WebSite/WebApplication on the home page only; use «Что за вино?» as the site name
<!-- labels: enhancement -->

**Priority:** P3 · **Effort:** S · **Status:** VERIFIED

## Problem

The global head prints the home-page `WebSite` and `WebApplication` entities (url = `/`) on every page, including legal pages and 404 pages. `WebSite.name` is «Что за вино? — поиск по фото». Google reads the site name from `WebSite` on the home page and expects the real name ([Google: site names](https://developers.google.com/search/docs/appearance/site-names)).

## Where

[`webui/nuxt.config.ts:72–99`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/nuxt.config.ts#L72-L99); test [`webui/tests/seo.test.ts:34–35`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/tests/seo.test.ts#L34-L35).

## Fix

- Move the block to `webui/app/pages/index.vue`.
- `name: 'Что за вино?'`, `alternateName: ['ЧтоЗаВино', 'chtozavino.ru']`.
- Other pages keep `isPartOf: { '@id': 'https://chtozavino.ru/#website' }`.
- Do not add ratings, `Product`, or price offers for wine.

## Verify

Rich Results Test and the Schema.org validator on `/`, `/android`, `/telegram-bot`.
