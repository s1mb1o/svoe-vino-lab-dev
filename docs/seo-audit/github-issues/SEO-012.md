**Priority:** P2 · **Effort:** S · **Status:** VERIFIED

## Problem

`main` adds the Shelf Lens landing page, its sitemap entry and a footer link (`cd8b063e`). Production does not have it yet.

- Production `sitemap.xml` has 16 URLs without `/shelf-lens`. `webui/public/sitemap.xml` on `main` has 17.
- Production static files have `Last-Modified: 2026-10-20 15:25 UTC`. This is between `831f66e2` (15:00 UTC) and `cd8b063e` (17:09 UTC).

## Where

[`webui/app/pages/shelf-lens.vue`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/app/pages/shelf-lens.vue), [`webui/public/sitemap.xml:16`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/public/sitemap.xml#L16), `webui/server/routes/shelf-lens-video/[filename].ts`.
