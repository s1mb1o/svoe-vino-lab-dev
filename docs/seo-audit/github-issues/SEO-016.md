SEO-016: Exclude the 18+ age-gate text from search snippets (data-nosnippet, Yandex <noindex>)
<!-- labels: enhancement -->

**Priority:** P2 · **Effort:** S · **Status:** VERIFIED presence, LIKELY impact

## Problem

The server HTML of every gated page contains the age-gate dialog after the page content (`<h2>Вам уже исполнилось 18 лет?</h2>` and its text). A crawler has empty storage, so the gate stays open. The content stays in the DOM, so indexing is not blocked. But the same gate text is on every page and can become the search snippet.

## Evidence

- 14 of 17 checked public pages contain the gate markup. `/terms`, `/privacy`, `/contacts` do not (by design).
- Headless Chrome screenshots (mobile Googlebot UA, 412 px) of `/`, `/dish`, `/lineup` were byte-identical: only the gate is visible.
- The gate H2 is the last heading of every gated page.

## Where

[`webui/app/components/AgeGate.vue:16`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/app/components/AgeGate.vue#L16), [`webui/app/app.vue:63`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/app/app.vue#L63), [`webui/app/assets/main.css:619–620`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/app/assets/main.css#L619-L620).

## Fix

Keep the gate. Add snippet and index exclusion markers:

```vue
<!-- AgeGate.vue -->
<div class="age-gate" aria-labelledby="age-heading" data-nosnippet>
  <noindex>
    <section class="age-card" …> … </section>
  </noindex>
</div>
```

```ts
// nuxt.config.ts
vue: { compilerOptions: { isCustomElement: tag => tag === 'noindex' } },
```

```css
/* main.css: keep the grid layout of .age-gate */
.age-gate > noindex { display: contents; }
```

References: [Google robots meta / data-nosnippet](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag), [Yandex: запрет индексирования части текста](https://yandex.ru/support/webmaster/adding-site/indexing-prohibition.html), [Google: mandatory interstitials](https://developers.google.com/search/docs/appearance/avoid-intrusive-interstitials).

Do not add a User-Agent bypass for bots.

## Verify

- Server HTML contains `data-nosnippet` and `<noindex>`; `webui/tests/seo.test.ts` passes.
- After reindexing: `site:chtozavino.ru` snippets in Google and Yandex do not show the gate text. Yandex Webmaster «Проверка ответа сервера» shows the robot's HTML.
