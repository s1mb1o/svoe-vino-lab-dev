SEO-029: Optional: accurate lastmod in sitemap.xml and Last-Modified/ETag on HTML
<!-- labels: enhancement -->

**Priority:** P3 · **Effort:** S · **Status:** VERIFIED

## Evidence

`sitemap.xml` has no `<lastmod>`. SSR HTML responses have no `Last-Modified` or `ETag`, so Yandex cannot use `If-Modified-Since`.

## Fix

Add `<lastmod>` only if it can be kept accurate (for example, generated from the git date of each page at build time). Otherwise leave it out: an inaccurate `lastmod` is ignored. HTML validators are optional.

## Verify

Sitemap validator; Yandex Webmaster «Проверка ответа сервера».
