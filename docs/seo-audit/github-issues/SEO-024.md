SEO-024: Add Cache-Control to static image folders (icons, line-wines, product-line-maps, …)
<!-- labels: enhancement -->

**Priority:** P3 · **Effort:** S · **Status:** VERIFIED

## Evidence

No `Cache-Control` on `/icons/*`, `/line-wines/*`, `/product-line-maps/**`, `/dishes/*`, `/crocodile/*`, `/game-art/*`, `/wines/*.webp`. Lighthouse «efficient cache policy»: 27 resources on `/lineup`.

## Where

[`webui/nuxt.config.ts:172–174`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/nuxt.config.ts#L172-L174) covers only `/reference/**` and two screenshot folders.

## Fix

Add the same bounded policy that the project already uses (`webui/ResearchLog.md:1395`):

```ts
'/icons/**': { headers: { 'cache-control': 'public, max-age=604800, stale-while-revalidate=86400' } },
'/line-wines/**': { headers: { 'cache-control': 'public, max-age=604800, stale-while-revalidate=86400' } },
'/product-line-maps/**': { headers: { 'cache-control': 'public, max-age=604800, stale-while-revalidate=86400' } },
'/dishes/**': { headers: { 'cache-control': 'public, max-age=604800, stale-while-revalidate=86400' } },
'/crocodile/**': { headers: { 'cache-control': 'public, max-age=604800, stale-while-revalidate=86400' } },
'/game-art/**': { headers: { 'cache-control': 'public, max-age=604800, stale-while-revalidate=86400' } },
'/shelf-lens/**': { headers: { 'cache-control': 'public, max-age=604800, stale-while-revalidate=86400' } },
```

## Side effect

A changed image with the same name can stay cached for up to 7 days.

## Verify

`curl -sI https://chtozavino.ru/icons/pwa-512.png | grep -i cache-control`.
