SEO-009: /shelf repeats the home page H1 «Найти вино по фото»
<!-- labels: bug -->

**Priority:** P2 · **Effort:** S · **Status:** VERIFIED

## Problem

`/` and `/shelf` have the same H1. The title of `/shelf` is specific («Найти вино на полке по фото»), but the main heading is not.

## Where

[`webui/app/components/ScannerPage.vue:29–30`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/app/components/ScannerPage.vue#L29-L30): the `v-else` branch serves both `bottle` and `shelf`.

## Fix

```vue
<h1 v-if="mode === 'dish'">Найти вино <span>к блюду</span></h1>
<h1 v-else-if="mode === 'shelf'">Найти вина <span>на полке</span></h1>
<h1 v-else>Найти вино <span>по фото</span></h1>
```

Keep the `/` H1 unchanged (`webui/docs/specification.md:65`).

## Verify

`curl -s https://chtozavino.ru/shelf | grep -o '<h1[^>]*>.*</h1>'`; browser checks for `/shelf` pass.
