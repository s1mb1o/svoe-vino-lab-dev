SEO-002: The 171 KB logo (PNG inside SVG) loads on every page and is shown at 44 px
<!-- labels: bug -->

**Priority:** P1 · **Effort:** S · **Status:** VERIFIED

## Problem

`/icons/product-logo.svg` is a 640×640 PNG in base64 inside an SVG `<image>`. It is 171,311 bytes (155 KB gzip transfer). It is the largest resource on `/`. It is displayed at 44×44 px in the header and in the age gate, and it is the favicon. The response has no `Cache-Control`.

## Evidence

- Lighthouse mobile, `/`: 168 KB image, first in the network list (before `background.webp` 93 KB and all JS).
- `curl -sI https://chtozavino.ru/icons/product-logo.svg` → no `cache-control`.

## Where

- [`webui/app/components/ProductBrand.vue:3`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/app/components/ProductBrand.vue#L3)
- [`webui/nuxt.config.ts:64`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/nuxt.config.ts#L64) (icon link)
- [`webui/tests/pwa.test.ts:46–47`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/tests/pwa.test.ts#L46-L47) (asserts the SVG link and that the file equals `assets/product-logo-640x640.svg`)
- `webui/docs/assets.md` line 227 (provenance)

## Fix

1. Make `webui/public/icons/product-logo-88.webp` (88×88, for 2× screens) and `webui/public/icons/favicon-120.png` (120×120) from `assets/product-logo-640x640.png`.
2. `ProductBrand.vue`: `<img src="/icons/product-logo-88.webp" alt="" width="44" height="44">`.
3. `nuxt.config.ts`: `{ rel: 'icon', type: 'image/png', sizes: '120x120', href: '/icons/favicon-120.png' }`. Yandex accepts 120×120 PNG ([help](https://yandex.ru/support/webmaster/search-results/favicon.html?lang=ru)).
4. Update the PWA test and `docs/assets.md`.
5. Cache headers for `/icons/**`: see SEO-024.

## Verify

- Lighthouse on `/`: no 168 KB image; transfer about 160 KB lower.
- `npm test` passes.
