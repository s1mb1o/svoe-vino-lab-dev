SEO-014: Optional URL normalization: trailing slash, upper case, UTM (Clean-param), single-hop http://www redirect
<!-- labels: enhancement -->

**Priority:** P3 · **Effort:** S · **Status:** VERIFIED

## Evidence

- `/shelf/`, `/SHELF`, `/shelf?x=1`, `/?utm_source=test` return 200. Each has the correct canonical (`/shelf` or `/`), so consolidation already works. Not urgent.
- `http://www.chtozavino.ru/` → 308 `https://www.chtozavino.ru/` → 308 `https://chtozavino.ru/` (two hops). The other host variants redirect in one hop.

## Where

[`webui/nuxt.config.ts:161–175`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/nuxt.config.ts#L161-L175) (route rules, no slash rule); `webui/public/robots.txt`; the `www` and HTTP redirects are in Caddy (deploy repository).

## Fix (choose what is worth it)

- `webui/public/robots.txt`: add `Clean-param: utm_source&utm_medium&utm_campaign&utm_content&utm_term` (Yandex).
- Caddy: redirect `http://www.chtozavino.ru` directly to `https://chtozavino.ru{uri}`.
- Optional: a Nitro middleware that 301-redirects a trailing slash and upper case to the canonical path for known HTML routes only. Keep functional queries (`/lineup/<id>?wine=…`). Exclude `/api`, `/v1`, `/downloads`, static folders.

## Verify

- `curl -sI http://www.chtozavino.ru/dish | grep -i location` → `https://chtozavino.ru/dish`.
- No redirect loops; queries kept; POST/API/media unchanged; Yandex Webmaster «Страницы в поиске» shows no duplicates.
