SEO-023: Replace the default English Nuxt 404 page with a Russian error page
<!-- labels: bug -->

**Priority:** P3 · **Effort:** S · **Status:** VERIFIED

## Evidence

`https://chtozavino.ru/nonexistent-page-xyz` (with `Accept: text/html`) → 404, `<title>404 - Page not found: … | Nuxt</title>`, English text, no site header or navigation, canonical `https://chtozavino.ru/` (SEO-019).

## Where

There is no `webui/app/error.vue`.

## Fix

Add `webui/app/error.vue`: Russian message, the site header, links to `/` and `/sitemap`, and

```ts
useSeoMeta({ title: 'Страница не найдена — Что за вино?', robots: 'noindex' })
```

SEO-019 removes the wrong canonical.

## Verify

The 404 page is in Russian with navigation; the status stays 404.
