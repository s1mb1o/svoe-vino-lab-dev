**Priority:** P2 · **Effort:** M · **Status:** VERIFIED (owner decision needed)

## Problem

The 25 producer maps are the deepest content of the site (for example, `/lineup/abrau-durso`: 1,180 words of groups, tiers and bottles). Each map sends `noindex, nofollow, noarchive` in the meta tag and in the `X-Robots-Tag` header, by design («review page»). The only indexable page for «российские винодельни» is the 319-word index `/lineup`.

## Options

1. **Keep noindex.** Add 1–2 factual sentences per producer card on `/lineup` (region, styles) from the map data. Effort S–M.
2. **Open reviewed maps.** Add a `reviewed: true` flag to the map JSON. Send `noindex` only for unreviewed maps (header and meta). Add reviewed maps to `public/sitemap.xml` and `app/data/sitemap.ts`. Set full OG tags on the map page. Fix SEO-006 first. Effort M.

## Legal note

A third-party page that singles out specific bottles can look like advertising (38-FZ art. 21). The maps show price tiers («Доступный сегмент · ₽») and no numeric prices. Keep it so. No buy links or shop prices.

## Verify (option 2)

Opened maps: 200, no `noindex` in either layer, in the sitemap; unreviewed maps still `noindex`.
