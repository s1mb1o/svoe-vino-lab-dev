SEO-019: Global canonical and og:url point to the home page on every page without an override
<!-- labels: bug -->

**Priority:** P2 · **Effort:** S · **Status:** VERIFIED

## Problem

The global head sets `<link rel="canonical" href="https://chtozavino.ru/">` and `og:url = https://chtozavino.ru/`. A page that does not override them claims to be the home page. This was correct when the portal had one page (`webui/ResearchLog.md`, around line 1388). The site now has 17 public pages. SEO-008 is one result.

## Evidence

| URL | canonical | og:url |
|---|---|---|
| `/account` (noindex) | `https://chtozavino.ru/` | `https://chtozavino.ru/` |
| `/shelf-lens`, `/nonexistent-page-xyz` (404) | `https://chtozavino.ru/` | `https://chtozavino.ru/` |
| `/lineup/abrau-durso` (noindex) | self | `https://chtozavino.ru/` |

## Where

- [`webui/nuxt.config.ts:47`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/nuxt.config.ts#L47) (`og:url`) and [`webui/nuxt.config.ts:63`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/nuxt.config.ts#L63) (`canonical`).
- [`webui/tests/seo.test.ts:28–35`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/tests/seo.test.ts#L28-L35) asserts both global values.

## Fix

1. Remove `og:url` and `canonical` from the global `app.head`.
2. Set them in `webui/app/pages/index.vue`:
   ```ts
   useHead({ title: 'Найти вино по фото — Что за вино?', link: [{ rel: 'canonical', href: 'https://chtozavino.ru/' }] })
   useSeoMeta({ ogUrl: 'https://chtozavino.ru/' })
   ```
3. Move the test assertion to `app/pages/index.vue`.
4. Optional: a test that each page in `app/data/sitemap.ts` sets `rel: 'canonical'` and `ogUrl`.

## Side effects

Noindex pages and the error page have no canonical. This is correct.

## Verify

- Built server: `curl -s localhost:8153/account | grep canonical` is empty; `/` has the home canonical.
- `npm test` passes.
