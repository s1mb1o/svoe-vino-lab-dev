SEO-003: /shelf loads three 2560×1928 example photos (2.26 MB) at first paint; lab LCP 15–16 s
<!-- labels: bug -->

**Priority:** P1 · **Effort:** S · **Status:** VERIFIED

## Problem

The «Вся полка» upload card shows one example photo and three picker thumbnails. All four `<img>` use the original 2560×1928 files that `scanner.example()` uploads for recognition. The preview is displayed at most about 600 px wide (210 px high on mobile). The thumbnails are 51×40 or 68×52 px.

## Evidence (Lighthouse 12.8.2, mobile, 2 runs)

| Metric | `/shelf` | `/` for comparison |
|---|---|---|
| Transfer | 2,915 KB | 660 KB |
| LCP | 15.9 s / 15.0 s | 4.8 s / 3.8 s |
| «Properly size images» | 2,225 KiB savings | — |

Files: `shelf-example-abrau-wide.webp` 878 KB, `shelf-example-sparkling-display.webp` 719 KB, `shelf-example-abrau-close.webp` 663 KB.

## Where

- [`webui/app/components/ShelfScanner.vue:70–72`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/app/components/ShelfScanner.vue#L70-L72)
- [`webui/shared/shelf.ts:14–33`](https://github.com/s1mb1o/svoe-vino-lab-dev/blob/cd8b063ecd000872567e543407b11926b45b3d37/webui/shared/shelf.ts#L14-L33) (one `src` per example)
- CSS sizes: `webui/app/assets/main.css` lines 494–499, 577–579

## Fix

1. Add `preview` (≈1280 px wide, WebP q≈75, ≤150 KB) and `thumb` (136×104 px, ≤8 KB) to `ShelfExample` in `shared/shelf.ts`. Keep `src` for the upload.
2. `ShelfScanner.vue:70`: `:src="shelfExample.preview"`, `width="1280" height="964"`, `fetchpriority="high"`.
3. `ShelfScanner.vue:72`: `:src="item.thumb"`, `width="68" height="52"`, `loading="lazy"`.
4. Record the derivatives in `webui/docs/assets.md`.

## Verify

- Lighthouse mobile `/shelf`: transfer < 900 KB; «Properly size images» passes.
- The example run still uploads the original file (shelf browser check).
