# on an excise mark beside an EAN (svoe-vino-matcher). 2.3.0 has no wheel for Python 3.14,
# so pip builds it from the source; this needs cmake and a C++ compiler:
#   ~/.venvs/svoe-vino-lab/bin/pip install --no-binary zxing-cpp zxing-cpp==2.3.0
