# Набор test-1

Набор содержит 54 магазинных фото из публичного исходного репозитория.
Исходный репозиторий не содержит эталонной разметки этих фото.
Разметка ниже получена отдельной проверкой видимого текста, бутылки и записей нашего каталога.
Ответы наших моделей не использовались как эталон.

## Состав

- 35 фото сопоставлены с записью `wine_catalog`.
- 13 фото помещены в `__null__`.
  Эти фото показывают определимый товар, для которого нет точной записи каталога.
- 6 фото помещены в `__drawer__` без метки.
  Эти фото показывают несколько разных товаров без однозначного главного объекта.

`review-labels.json` является импортируемой разметкой.
`mapping.json` содержит решение и основание для каждого из 54 фото.
`variant-groups.json` задаёт три группы эквивалентных карточек каталога.
