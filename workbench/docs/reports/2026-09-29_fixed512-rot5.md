# Fixed-512 reference rotation at 5-degree steps

The owner requested this experiment on 2026-09-29.

Configuration: `barcode-rerank-siglip2-512-rot5-seg`.

Test set: `my`.

## Method

- Use the fixed-resolution SigLIP2 SO400M patch16 512 model.
- Embed each full reference at 0°, 5°, 10°, …, 355°.
- Keep label references unrotated.
- Keep the baseline query steps: package segmentation, background removal, white
  background, and resize. Each query has one embedding.
- Keep barcode lookup, cluster reranking, and four run workers.
- Use six reference-build workers and batches of 36 images.
- Build the clusters from the 0° full vectors and unrotated label vectors.
- Copy the existing label-rule cache. The standard rule builder checks its input
  hashes and rebuilds only changed descriptions or rules.
- Use the normal model caches. Timing is not a test of uncached latency.
