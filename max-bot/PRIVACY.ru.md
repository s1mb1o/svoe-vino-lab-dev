# Политика обработки данных бота «Что за вино?» в MAX

Дата редакции: 20 октября 2026 года.

## Какие данные обрабатываются

Бот обрабатывает фотографию, которую пользователь отправил боту.
Бот сохраняет MAX user ID пользователя.
Бот также сохраняет доступные имя, фамилию и username на момент запроса.
Бот сохраняет выбор пользователя в подтверждении возраста и дату выбора.
Бот сохраняет дату запроса, результат проверки безопасности и результат распознавания.
Бот сохраняет перцептивные хеши изображения и результаты проверки качества.
Бот сохраняет ранжированные варианты распознавания и их оценки.
Бот сохраняет оценку совпадения, выбранный альтернативный вариант и дату оценки.
Бот сохраняет обращение об ошибке фильтра, если пользователь нажал соответствующую кнопку.
Бот сохраняет техническое время ожидания и длительность этапов обработки.

## Для чего используются данные

Данные используются для распознавания вина.
Данные также используются для проверки и улучшения качества распознавания.
Оценка совпадения используется для измерения качества распознавания.
Перцептивные хеши используются для поиска одинаковых и похожих изображений.
Агрегированная статистика используется для оценки работы сервиса.

## Проверка безопасности

Каждая фотография проходит автоматическую проверку до записи файла на диск.
В рабочей версии сервиса проверка безопасности всегда включена.
Фотография с потенциально недопустимым содержимым сохраняется в отдельном закрытом хранилище.
Такая фотография не отправляется в сервис распознавания.
Автоматическая проверка может ошибаться.

## Хранение

Данные хранятся на сервере проекта.
Бот автоматически удаляет фотографии, артефакты обработки и данные запроса через 30 дней.
Бот также удаляет профиль пользователя, если у него не осталось сохранённых запросов.
Доступ к данным имеет владелец проекта.

## Передача данных

MAX обрабатывает сообщения по своим правилам до передачи сообщения боту.
Бот не публикует фотографии и данные пользователя.
Бот не отправляет фотографию на сайт `vino-svoe.ru`.
Бот возвращает только ссылку на страницу найденного вина.

## «Винный дневник»

Пользователь может привязать MAX к своему «Винному дневнику» в мини-приложении дневника.
Бот не хранит привязку. Сервис дневника хранит MAX user ID привязанного пользователя.
Если MAX привязан к «Винному дневнику», бот передаёт в дневник найденное вино.
Бот передаёт название, винодельню, цвет, сахар, регион и сорта винограда вина.
Сервис дневника сохраняет вино и дату в истории дневника.
Фотография в дневник не передаётся.
Переключатель «Записывать найденные вина» на сайте выключает запись.
Кнопка «❌ Не совпало» удаляет запись этого вина за сегодня.
Выбранный вариант записывается вместо показанного вина.
Пользователь может удалить одно вино или всю историю на странице дневника.
Удаление дневника удаляет историю и привязку.

## Права пользователя

Пользователь может запросить удаление своих данных раньше автоматического срока.
Для запроса нужно написать `@s1mb1o` и указать MAX user ID.
Бот показывает MAX user ID пользователя в ответе на команду `/privacy`.
