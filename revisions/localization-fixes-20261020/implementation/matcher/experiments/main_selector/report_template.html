Intent decisions and crop pixels are different measurements.

Passive intent targets, explicit interactions, GT-geometry policy targets, no-target negatives and rule fixtures are separate cohorts. There is no combined accuracy headline. Both selectors consume the same frozen detector inputs for this comparison; any recovery profile is identified in the revision audit. Production scene-v1 uses five nouns and has not been remeasured here. Controlled mode supplies GT-derived detector fixtures and named faults. It is a rule/crop regression, not detector accuracy.

Decision metrics compare the chosen region's assigned target ID. Pixel metrics compare the actual emitted crop with the original photo inside the keep mask, independently of that ID. Identical full-frame outputs therefore receive identical label retention and target coverage. Full-frame context can preserve every label pixel and retain every distractor: read both columns. No wine identity accuracy is measured. COCO uses a generic bottle category; the beverage identity of every imported bottle has not been independently verified.

Policy targets are generated from original visible GT geometry and frozen before replay. ID-only matches and the joint ID + required fallback-mode contract are reported separately; exact GT distance ties are exposed. They are product-default conformance, not evidence of user intent. The rule-fixture mode is a new-contract check for semantic-v2 only, not a head-to-head accuracy benchmark. Interaction photos test a capability scene-v1 does not have. New views share scene assets and are correlated coverage, not independent accuracy evidence. New real photos have source bottle polygons, no invented label masks, and may have incomplete background instance coverage.
