# shelf-reid

Поиск уникальных бутылок полки на нескольких фото или кадрах видео. Цель — не
распознавать одну и ту же бутылку дважды, в том числе после разрыва съёмки
(полка A → полка B → снова A).

Идентичность бутылки — это её место на полке, а не внешний вид: бутылки одного вина
стоят рядом и выглядят одинаково. Кадры связываются гомографией лицевой плоскости
полки, бутылки нового кадра сравниваются с известными по положению. Подробности —
в [docs/design.md](docs/design.md).

## Состояние

| Этап | Статус |
|---|---|
| Два кадра с перекрытием: гомография, перенос бутылок, венгерский алгоритм | готово, тесты на синтетике |
| Синтетические полки с известным ответом | готово |
| Выпрямление фишая (модель деления, подбор по прямым линиям) | готово |
| Видео: поворот, выпрямление, чтение кадров | готово |
| Детектор бутылок | базовый: COCO `bottle` из torchvision + чистка |
| Замер связывания кадров по перекрытию | `scripts/eval_overlap.py` |
| ALIKED / DISK + LightGlue (`uv sync --extra deep`), точки только на бутылках | готово, пресет `pair.ROBUST` |
| Оценка решений по бутылкам против треков видео | `scripts/eval_bottles.py` |
| Поток: оптический поток, карта, ключевые кадры, замыкание петли, зелёные/красные рамки | готово (`stream.py`, `scripts/run_stream.py`) |
| Кэш детекций видео | `scripts/detect_video.py` |
| Телефон: детектор, трекер, отправка лучшего кропа | нет |

## Запуск

```bash
uv sync
uv run pytest -q

# Связать два снимка без детекций: рамка кадра B на кадре A и совпавшие точки.
uv run shelfreid register a.jpg b.jpg --out out/register.jpg

# Какие бутылки кадра B уже были в кадре A.
uv run shelfreid pair a.jpg b.jpg --dets-a a.json --dets-b b.json --out out/pair.jpg

# Синтетические пары с известным ответом.
uv run shelfreid synth --count 5 --overlap 0.5
```

Формат детекций: `[{"box": [x1, y1, x2, y2], "id": "...", "score": 0.9}, ...]` в
пикселях исходного кадра.

## Структура

| Модуль | Назначение |
|---|---|
| `features.py` | ключевые точки (SIFT, ORB, AKAZE) и сопоставление с тестом Лоу |
| `homography.py` | гомография B → A (MAGSAC) и проверка правдоподобия |
| `associate.py` | перенос бутылок B в координаты A и назначение венгерским алгоритмом |
| `pair.py` | два кадра целиком: `match_pair` |
| `synth.py` | синтетическая полка и два вида с известной гомографией |
| `camera.py` | дисторсия: модель деления, её подбор, карты выпрямления |
| `video.py` | кадры видео: поворот, масштаб, выпрямление; пресет `LENTA_ROBOT` |
| `detect.py` | детектор бутылок COCO (torch и torchvision ставятся отдельно) и чистка рамок |
| `panorama.py` | склейка ключевых кадров для проверки глазами |
| `stream.py` | потоковый трекер уникальных бутылок (алгоритм для телефона) |
| `viz.py` | картинки регистрации и решений |
| `cli.py` | команды `register`, `pair`, `synth` |

Данные (видео, кадры, фото) лежат в `data/`, результаты — в `out/`. Обе папки не
попадают в git.
