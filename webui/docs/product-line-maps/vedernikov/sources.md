## Official collections

[The official collection page](https://vedernikovwine.ru/vino/) identifies three collections. It calls `Твердый Знак` the flagship. It calls `Резерв` a premium aged collection. It describes the main collection separately. The tier order follows these statements. It does not represent current retail prices.

- [Main collection](https://vedernikovwine.ru/vino/vinodelnya-vedernikov/) supports the main collection. The navigation group `Основная линейка и другие вина` also contains snapshot cards without a clear named series. Their membership in the official main collection is not verified. The group description states this limit. Separate vintages and packages are not merged.
- [Reserve collection](https://vedernikovwine.ru/vino/vinodelnya-vedernikov-rezerv/) supports the reserve group. Only snapshot names that explicitly contain `Резерв` enter this group. Gubernatorskoe reserve stays separate.
- [Tverdy Znak](https://vedernikovwine.ru/vino/vinodelnya-vedernikov-tverdyy-znak/vinodelnya-vedernikov-tverdyy-znak1/) confirms the first flagship blend.
- [Tverdy Znak No.2](https://vedernikovwine.ru/vino/vinodelnya-vedernikov-tverdyy-znak/vinodelnya-vedernikov-tverdyy-znak-2/) confirms the second flagship blend.

The last two products are absent from the 43 snapshot names and slugs. They have null wine slugs. Their exact source URLs and original WebP image URLs are in the crosswalk. Both source pages state bounded release quantities. Their release status is limited.

## Conservative grouping

`Губернаторское`, `Губернаторский Резерв`, `Фантом`, `Правобережное`, and `Долина Дона` are explicit snapshot names. Their current official hierarchy was not established. These groups use the neutral tier. No discontinued status is inferred.

`Пет-Нат` and `Игристые из каталога` are navigation groups. They are not claims of official collection names. They use the neutral tier. The snapshot `Сибирьковый-Алиготе` card is explicitly assigned to the sparkling group. The official reserve collection also lists this blend. No claim of the same reserve package is made.

This is complete snapshot coverage with two verified additions. It is not complete coverage of every current official product. No numeric prices are asserted. `catalog` means source evidence, not retail stock.
