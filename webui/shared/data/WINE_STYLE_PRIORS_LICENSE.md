# Wine style aggregate license

`wine-style-priors.json` is an aggregate adaptation of `winemag-data-130k-v2.csv`.

Source: [Wine Reviews](https://www.kaggle.com/datasets/zynicide/wine-reviews).

The source dataset uses the Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International license.

The aggregate file uses the same license.

The aggregate file contains descriptor frequencies and structural averages by grape variety.
It does not contain review text.
It does not contain a critic score.
